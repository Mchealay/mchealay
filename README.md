### 🔬 Project Deep-Dives

<details>
<summary><strong>🤟 TASL — First Real-Time Tigrinya Sign Language Recognition System</strong></summary>
<br/>

> *Oct 2025 – Feb 2026 · AI & Computer Vision*

**The Problem:** Tigray's Deaf community faced major communication barriers due to a lack of real-time translation tools tailored for Tigrinya sign alphabets.

**The Solution:** Engineered an end-to-end computer vision pipeline using Python, OpenCV, and MediaPipe. Trained custom AI models on **20,000+ images** for 30 distinct Tigrinya letters (ሀ-ፐ), delivering **sub-50ms** instant text & synthesized audio feedback via live webcam stream.

- ✅ Recognizes all 30 Tigrinya letters (ሀ-ፐ) via webcam in real time
- ✅ Trained on 20,000+ custom annotated image samples
- ✅ Real-time audio speech synthesis & instant visual feedback
- ✅ Built for inclusive education and accessible communication

[🔗 GitHub Repository](https://github.com/Mchealay/sign-language)
</details>

<details>
<summary><strong>💼 SkillSync — AI-Powered Career Coach SaaS</strong></summary>
<br/>

> *Feb 2026 – May 2026 · Full-Stack SaaS*

**The Problem:** Job seekers struggle to optimize resumes for ATS filters and identify actionable skill gaps for target roles.

**The Solution:** Architected a Next.js 19 SaaS platform integrated with Google Gemini API, NeonDB PostgreSQL, and Clerk Authentication. Delivers intelligent resume scoring, custom career roadmaps, and real-time job recommendations.

- ✅ Instant AI resume review with line-by-line breakdown
- ✅ Automated job recommendations tailored to skill profile
- ✅ PostgreSQL data persistence via NeonDB & Clerk Auth
- ✅ Responsive React 19 UI with fluid Tailwind CSS styling

[🔗 GitHub Repository](https://github.com/mchealay/SkillSync-AI-Career-Coach)
</details>

<details>
<summary><strong>🏥 EHealthSuite — Multi-Tenant Enterprise Insurance Platform</strong></summary>
<br/>

> *Mar 2025 – May 2025 · Enterprise Backend*

**The Solution:** Designed a multi-tenant backend architecture with NestJS and PostgreSQL. Implemented tenant-isolated database schemas, policy workflows, claim verification rules, and role-based access control (RBAC).

- ✅ Multi-tenant data isolation with dynamic PostgreSQL schema switching
- ✅ Automated claim processing workflow with rule-based validation
- ✅ Provider network management and policy member registry
- ✅ Clean NestJS modular architecture with Dependency Injection

[🔗 GitHub Repository](https://github.com/EthiopianInsuranceCoorpration/EIC)
</details>
